## 这款光影是什么

**SEUS** 是 **Sonic Ether’s Unbelievable Shaders** 的缩写，由 **Sonic Ether（Cody Darr）** 创作，是用于 Minecraft Java 版的光影项目。**SEUS Renewed** 是对其早期光影版本的重新设计，采用传统光栅化渲染，着重于光照、阴影、水面与大气效果。[原作者介绍](https://www.sonicether.com/seus/)

本次修补所基于的原光影版本是 **SEUS Renewed 1.0.1**，官方页面标注发布日期为 **2020 年 2 月 10 日**。它与原作者的 **SEUS PTGI** 属于不同系列；本仓库不会将 Renewed 转换成 PTGI，也不会增加完整路径追踪渲染器。[官方版本与下载说明](https://sonicether.com/shaders/download/renewed-v1-0-1/)

### 为什么需要 DH 适配

**Distant Horizons（遥远的地平线，简称 DH）** 使用较低细节的远景模型扩展可见范围。近景原版区块与远景 LOD 分别经过不同的几何和深度处理，因此光影需要对应的兼容逻辑，才能把远景地形与水面接入同一套光照和合成效果。

本次输入的 `DH-ZH-v0.5.2` 已包含 DH 接入和中文选项。**这些适配与汉化在本次工作开始前就已存在，本仓库仅修补其中定位到的水面问题，不宣称从零实现 DH 支持或汉化。** 官方原包不能直接替代这一输入包。

## 使用

需要 Windows PowerShell 5.1 或 PowerShell 7，以及用户已合法取得的上述适配包。

下载本仓库，将 `Patch-SEUS-Water.ps1` 与 `option-descriptions.json` 保持在同一文件夹。在该文件夹打开 PowerShell，执行：

```powershell
.\Patch-SEUS-Water.ps1 -InputZip 'D:\shaderpacks\SEUS-Renewed-v1.0.1-DH-ZH-v0.5.2.zip'
```

默认在输入文件旁生成 `SEUS-Renewed-v1.0.1-DH-ZH-v0.5.4-waterfix.zip`。原文件不覆盖，已有输出文件也不覆盖；可用 `-OutputZip` 指定另一个尚不存在的输出路径。

在游戏中选择生成的 ZIP，将光影设置中的“远景水面反射”保持为 **1.0**。生成的完整光影包仅供本地个人使用；未经所需授权，请勿上传 GitHub Release、网盘或其他镜像。

## 最终版修正

- **远海暗色带**：水上视角的水面反射射线改为取样不透明深度层，避免命中水面自身、用水体底色盖住天空倒影；同时跳过天空的空深度样本。水下全内反射保留原来的透明深度路径。
- **近远亮度接缝**：远景透明层采用与近景 SEUS 水面一致的光照坐标和编码。原适配的满天空光照经过曲线后，约为近景的 2.054 倍；修补后映射一致。
- **反射强度**：远景水反射默认值由 0.5 调整为 1.0，并更新中英文选项提示。

主世界、下界和末地的反射代码同步修改；共享水面光照代码一并修改。v0.5.3 只调整反射强度，没有解决后来定位的两个问题，本仓库发布的是最终 v0.5.4 修补。

## 验证范围

测试环境：Minecraft 1.21.1、Iris NeoForge 1.8.14-beta.1、Distant Horizons 3.3.3。

已在主世界海面视角进行材质、法线、光照、反射命中及合成阶段诊断；反射修正后测试视角中的远海暗带消失。正式包已成功编译加载。全部 16 档光照映射逐一核对，公式差值为 0。

下界、末地虽同步修改代码，尚未进行相应维度的画面验证；未专门进行水下画面对比。不同版本、场景与 LOD 精度下的效果仍需自行验证。

画面和帧率还受显卡、分辨率、资源包、近景区块距离、DH 远景距离与质量等因素影响。本次没有建立跨硬件的性能基准，也没有验证其他 Minecraft、Iris、OptiFine 或 DH 版本组合。远景 LOD 保留较低几何细节，水底形状、岸线与局部倒影仍可能和近景存在差异；本修补解决已定位的反射误命中和光照编码问题，不把远景 LOD 变成完整原版区块。
