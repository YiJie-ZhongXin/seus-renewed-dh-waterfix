## 使用

需要 Windows PowerShell 5.1 或 PowerShell 7，以及用户已合法取得的上述适配包。

下载本仓库，将 `Patch-SEUS-Water.ps1` 与 `option-descriptions.json` 保持在同一文件夹。在该文件夹打开 PowerShell，执行：

```powershell
.\Patch-SEUS-Water.ps1 -InputZip 'D:\shaderpacks\SEUS-Renewed-v1.0.1-DH-ZH-v0.5.2.zip'
```

默认在输入文件旁生成 `SEUS-Renewed-v1.0.1-DH-ZH-v0.5.4-waterfix.zip`。原文件不覆盖，已有输出文件也不覆盖；可用 `-OutputZip` 指定另一个尚不存在的输出路径。

在游戏中选择生成的 ZIP，将光影设置中的“远景水面反射”保持为 **1.0**。生成的完整光影包仅供本地个人使用；未经所需授权，请勿上传 GitHub Release、网盘或其他镜像。

## 最终版修正

- **远海暗色带**：水上视角的水面反射射线改为取样不透明深度层，避免命中水面自身、用水体底色盖住天空倒影；同时跳过天空的空深度样本。水下全内反射保留原来的透明深度路径。
- **近远亮度接缝**：远景透明层采用与近景 SEUS 水面一致的光照坐标和编码。原适配的满天空光照经过曲线后，约为近景的 2.054 倍；修补后映射一致。
- **反射强度**：远景水反射默认值由 0.5 调整为 1.0，并更新中英文选项提示。

主世界、下界和末地的反射代码同步修改；共享水面光照代码一并修改。v0.5.3 只调整反射强度，没有解决后来定位的两个问题，本仓库发布的是最终 v0.5.4 修补。
